Webflow Designer Extension · Designer API

Catch accessibility and SEO issues while you design.

This extension runs in the Webflow Designer's side panel. It checks the current page for heading-order mistakes, missing or file-name alt text, vague or empty links, and title, meta and Open Graph gaps. Click an issue to select that element on the canvas, or fix a heading level in one click. Here the extension runs against a simulated Designer that implements the same API methods.

Simulated canvas selection and fixes made by the extension show up here

Run it in the real Designer

npm i -g @webflow/webflow-cli
git clone https://github.com/mizcausevic-dev/webflow-a11y-seo-auditor && cd webflow-a11y-seo-auditor
webflow extension serve        # serves ./public on localhost:1337
# Webflow Designer → Apps → your registered App → Launch development App
webflow extension bundle       # bundle.zip to upload for your App

You need a Webflow App registered in your Workspace with the Designer Extension capability turned on. The extension only reads the page, except when you click "Fix level", which calls setHeadingLevel().
